# 📖 Flashcards Bíblicos

Projeto web com flashcards interativos de perguntas e respostas sobre a Bíblia. Desenvolvido com HTML, CSS e JavaScript.

## ✨ Funcionalidades

- 10 perguntas bíblicas com respostas reveladas ao clicar
- Design responsivo com menu hamburger para dispositivos móveis
- Interface simples e acessível
